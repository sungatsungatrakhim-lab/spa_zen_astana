# spa_zen_astana

Сайт спа-салона **Zen** (Астана): анимированный лендинг с онлайн-записью.

Vite + React 19 + TypeScript + Tailwind CSS v4.

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

## Что внутри

- **Тёмный первый экран** (`src/motion/IntroStage.tsx`): буквы «ZEN» собираются, фото в арке поднимается, при прокрутке экран приближается, затем сайт выезжает поверх.
- **Стопка секций** (`src/motion/Stack.tsx`): секции наезжают друг на друга, предыдущая уменьшается и затемняется.
- **Анимации появления** (`src/motion/motion.ts`): заголовки со сжатием букв, шторки на фото, параллакс, плавная прокрутка (Lenis), курсор «Смотреть», прелоадер.
- **Онлайн-запись** (`src/booking/`): 4 шага — услуга → мастер → дата и время → данные, итог и экран подтверждения. Открывается любой кнопкой «Запись».
- **Контент** — `src/data/content.ts`, услуги/мастера/цены для записи — `src/booking/data.ts`.

## Важно

- Запись работает в демо-режиме: занятость времени условная, заявка никуда не отправляется. Для реальной работы подключите WhatsApp, Telegram-бот или CRM (Altegio, YCLIENTS).
- Цены, мастера, отзыв и тексты статей — примеры, замените на свои.
- Холст сайта свёрстан по макету 1440px; на узких экранах он пропорционально уменьшается.
